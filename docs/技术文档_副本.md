## 1. 项目概述

### 1.1 项目背景

梵音阁是一个佛教文化珍品电商平台，提供佛像、手串、香炉、经书、法器等佛教文化产品的在线展示与销售。

### 1.2 核心特性

- 双语支持（中/英）
- 佛教美学设计风格
- 产品展示与筛选
- 购物车功能
- 订单管理
- 后台管理系统

### 1.3 访问地址

- 前台：`http://localhost:3000`
- 后台：`http://localhost:3000/admin`
- 管理登录：`/admin/login`（密码：buddhist2026）

## 6. 数据模型

### 6.1 Supabase 数据库表

> 注意：以下为设计表结构，实际产品数据目前为硬编码

#### products（产品表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| name | text | 中文名称 |
| name_en | text | 英文名称 |
| slug | text | URL slug |
| description | text | 简短描述 |
| description_long | text | 长描述（中文） |
| description_long_en | text | 长描述（英文） |
| price | numeric | 价格 |
| original_price | numeric | 原价 |
| stock | integer | 库存 |
| images | jsonb | 图片数组 |
| category_id | uuid | 分类 ID |
| material | text | 材质 |
| use_case | text | 用途 |
| tags | jsonb | 标签数组 |
| status | text | 状态 (active/inactive/draft) |
| featured | boolean | 是否推荐 |
| created_at | timestamp | 创建时间 |

#### categories（分类表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| name | text | 分类名称 |
| name_en | text | 英文名称 |
| slug | text | URL slug |
| description | text | 描述 |
| image_url | text | 图片 URL |
| sort_order | integer | 排序 |
| created_at | timestamp | 创建时间 |

#### orders（订单表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| order_number | text | 订单号 |
| user_id | uuid | 用户 ID |
| status | text | 状态 (pending/paid/processing/shipped/delivered/cancelled) |
| total_amount | numeric | 总金额 |
| currency | text | 货币 (CNY/USD) |
| payment_method | text | 支付方式 |
| shipping_name | text | 收货人 |
| shipping_phone | text | 电话 |
| shipping_address | text | 地址 |
| created_at | timestamp | 创建时间 |
| updated_at | timestamp | 更新时间 |

#### order_items（订单明细表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| order_id | uuid | 订单 ID |
| product_id | uuid | 产品 ID |
| product_name | text | 产品名称 |
| price | numeric | 价格 |
| quantity | integer | 数量 |

#### profiles（用户资料表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 (关联 auth.users) |
| email | text | 邮箱 |
| full_name | text | 姓名 |
| phone | text | 电话 |
| avatar_url | text | 头像 URL |
| language | text | 语言偏好 (zh/en) |
| created_at | timestamp | 创建时间 |

### 6.2 本地存储 (localStorage)

| Key | 用途 |
|-----|------|
| language | 语言偏好 (zh/en) |
| cart | 购物车数据 |
| user | 登录用户信息 |
| orders | 订单列表 |
| admin_session | 管理员会话 |
